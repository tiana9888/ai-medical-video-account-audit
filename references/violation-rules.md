# 视频号违规规则与处罚体系

## 一、监管框架：四大核心规范文件

| 规范文件 | 核心管什么 | 适用性 |
|---|---|---|
| 《视频号医疗健康行业公约》（2026.4.1生效） | 医疗健康内容的资质准入、内容规范、账号规范 | AI医疗品牌所有内容都受此约束 |
| 《视频号常见违规内容概览》 | 账号违规、侵权、低俗、过度营销、标题/封面不相关等通用违规 | 所有视频，特别是标题、封面、文案 |
| 《微信视频号运营规范》 | 账号注册、命名、信息发布、禁止内容总纲 | 账号名称、简介、背景图 |
| 《视频号视频营销信息发布规范》 | 营销信息发布规范，含绝对化用语、虚假宣传、导流 | 产品功能展示、推广时适用 |

2025年8月四部门（网信办、卫健委、市场监管总局、中医药局）联合发文：**严禁无资质账号发布专业医疗科普内容**，平台须对违规账号采取取消互动功能、清理粉丝、关闭等梯度处罚。

## 二、医疗健康内容定义（8类）

涉及以下任一方面即被认定为医疗健康内容，未认证发布即违规：

1. **疾病原理** — 讲解疾病发生机制
2. **对人体的影响** — 疾病/症状对人体机能的影响
3. **诊断过程** — 展示或讲解如何诊断疾病
4. **治疗手段或方案** — 介绍治疗方法、方案
5. **缓解预防** — 讲解如何缓解或预防疾病
6. **康复手段** — 康复训练、康复方案
7. **食疗** — 以饮食调理疾病
8. **急救手段** — 急救方法、紧急处理

## 三、三类违规原因

### 类型A · 发布疾病相关内容/营造医疗身份

- **违规依据**：《视频号资质管理规范》
- **触发条件**：发布疾病原理、预防、诊断、治疗方案、用药、医疗器械演示、紧急救治等；发布具有治疗效果的偏方、药方、方法；营造医疗身份（白大褂、自称医生等）
- **处罚**：视频减少推荐

### 类型B · 疑似引导线上讨论/线下问诊/医疗教学

- **违规依据**：《视频号常见违规内容概览》
- **触发条件**：引导用户线上/线下问诊；引导评论区讨论病情；引导到视频号外学习医疗知识/领取医疗资料
- **处罚**：暂不可传播（视频被完全下架，比"减少推荐"更严重）

### 类型C · 发布药品/医疗器械/医疗服务科普营销内容

- **违规依据**：《视频号常见违规内容概览》
- **触发条件**：长篇幅介绍药品/医疗器械/医疗服务；营销推广药品/医疗器械/医疗咨询/医疗课程；宣传产品具备缓解/预防/治疗疾病效果
- **处罚**：暂不可传播

## 四、认证后的限制（即使认证了也有限制）

- **不能带货**：医疗类账号暂停商品信息分享功能
- **不能投流**：2022年8月1日起停止对医疗类账号提供流量包服务
- **不能私域引流**：关闭医疗资质账号的客服、公众号关联及私信功能（公立三甲医院除外）
- **禁止引导讨论病情**
- **禁止医疗教学**
- **禁止MCN运营**：医疗类账号交由他人或MCN运营，永久封禁

---

## 五、医疗内容17条禁止项（即使有资质也禁止）

1. 片面解读或夸大医疗知识（"包治""100%""根除"等绝对化用语）
2. 传播未经验证的偏方、古方和错误的医疗知识
3. 借用医生/医院身份背书推广产品
4. 宣传或开展有偿献血、代孕
5. 传播高危且易被模仿的医疗内容（正骨、针灸、感统训练等详细教学）
6. 利用两性擦边或低俗话题讲解医疗知识
7. 发布易引人不适的血腥、色情内容
8. **在非广告场景发布药品、医疗器械、医疗服务、医学课程等营销内容**
9. **讲解药品时直接提及商品名和品牌名**（应使用通用名）
10. 通过摆拍患者不适症状博取关注
11. **养生内容中宣称某种方式具有治疗疾病的效果**
12. 散布医疗有害信息、虚假内容
13. 仿冒他人身份传播医疗养生内容
14. 宣传夸大或虚假功效的养生方法/产品/服务
15. **展示联系方式或以领取资料为诱饵诱导用户脱离视频号场景**
16. 发布医疗IP孵化、医疗账号代运营等商业服务内容
17. 过度美化个人医德医术，营造悬壶济世形象

## 六、2025-2026年专项治理重点

- 编造医疗谣言、宣扬未证实偏方（如"A+B食材赶走XX疾病"）
- 夸大普通食材的医疗功效
- 以"一个动作告别XX疾病"等话术传播伪科学
- 利用AI工具改变面部形象或遮挡面部规避资质核验
- 宣扬疗愈性音乐具有疾病治疗功效
- 将用户诱导至私域或第三方平台购买医疗/保健产品

## 七、违规处罚梯度

| 级别 | 触发条件 | 处罚措施 |
|---|---|---|
| 轻度 | 内容质量低、广告占比过高 | 当前视频限流 |
| 中度 | 发布违规内容但情节一般 | 视频删除、暂不可传播 |
| 重度 | 反复违规或情节严重 | 账号限流、减少推荐 |
| 特别严重 | 严重违法（诈骗、色情等） | 封禁账号 |

### 医疗内容专项处罚

| 违规行为 | 处罚措施 |
|---|---|
| 无资质发布专业医疗科普 | 视频限流/删除 → 账号限流 → 取消互动功能 → 清理粉丝 → 关闭账号 |
| 编造医疗谣言/传播伪科学偏方 | 短期或永久限制内容传播 |
| 利用AI改变面部规避资质核验 | 取消"健康科普"资质、短期或永久取消直播资质申请权限 |
| 将用户诱导至私域购买医疗产品 | 停止提供直播服务 |
| 反复违规 | 加大处罚力度，包括永久取消直播/发布资质 |

## 八、申诉机制

- 违规通知后可在 **180天内** 提交申诉/提交资质
- 提交资质后审核通过，视频将重新获得推荐
- 申诉入口：视频号创作者后台 → 账号诊断 → 提交反馈
- 申诉材料：原创证明、版权授权书、资质证明等

---

## 九、资质认证路径

### 路径A · 机构认证（推荐优先）
- 公司主体完成企业认证
- 选择"医疗健康-民营医院/公立医院"行业
- 上传医疗机构执业许可证等证明
- 审核通过后已有视频可恢复推荐

### 路径B · 个人职业认证
- 执业医师/药师/护士完成个人职业认证

### 路径C · 媒体认证
- 事业媒体/企业媒体认证

**注意**：即使认证通过，医疗类账号仍不能带货、不能投流、不能私信引流。若短期内无法完成认证，账号定位必须从"健康助手"调整为"AI科技产品"，避免在账号名称、简介、背景图中出现"医生""健康""医疗"等可能触发资质要求的词汇。
