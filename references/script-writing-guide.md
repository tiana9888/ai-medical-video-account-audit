# 前期脚本撰写合规指南

## 一、标题撰写规则

### 1.1 禁止出现的词汇类型

| 类别 | 示例 | 说明 |
|---|---|---|
| 绝对化用语 | 最、第一、顶级、100%、唯一、首选、极致、永久、万能 | 违反《广告法》，全行业禁用 |
| 疾病名称 | 脑梗、肺炎、高血压、糖尿病、癌症 | 无医疗资质时绝对不可出现 |
| 症状名称 | 头晕、胸痛、发烧、肚子疼、失眠 | 被认定为医疗内容的触发词 |
| 药物名称 | 氨氯地平、二甲双胍、阿司匹林 | 涉及用药科普，需资质 |
| 权威背书词 | 国家领导人推荐、三甲医院推荐、央视推荐、中国驰名商标 | 虚假宣传，严禁 |
| 诱导消费词 | 秒杀、抢疯了、最后一波、错过再无、万人疯抢 | 激发抢购心理，违规 |
| 导流词 | 加微信、私聊、扫码、进群、加v | 平台零容忍导流行为 |
| 迷信词 | 招财、旺宅、辟邪、转运、风水、开光 | 封建迷信内容 |
| 虚假承诺词 | 稳赚不赔、保本、包过、快速赚钱 | 涉及金融/教育虚假承诺 |

### 1.2 标题撰写原则

- 标题文案与视频内容必须**高度相关**，题文不符将被处罚
- 不得使用过度夸张的描述煽动用户
- 不得使用侮辱、脏话词汇
- 不得隐晦引导（如"附近100米""加微"等引人遐想的信息）
- 不得使用谐音、拼音、emoji变体规避审核（2026年AI识别已升级，可识别变体）

### 1.3 标题改写示例

| 原标题（违规示例） | 改写示例 |
|---|---|
| 查XX却被劝去查YY？AI助手看穿隐秘病灶 | AI的推理能力有多强？同一个问题它发现了别人忽略的线索 |
| 用药安全无小事！先理清楚再给建议 | AI的信息梳理能力：它怎么帮你看懂复杂说明 |
| 同样是XX不适，年轻人没事，老年人却必须重视？ | 同一个问题，AI会根据不同情况给出不同判断 |
| 身体不适别乱猜，AI助手帮你梳理出重点 | 问AI一个问题，它反而先问你三个问题——这就是AI的严谨 |
| 年年体检正常，为什么还是查出了问题？ | AI的长期记忆：它比你更记得你说过什么 |
| 体检报告越攒越慌？AI助手三步帮你理清健康头绪 | 满屏箭头看不懂？AI帮你把杂乱信息整理成一句话 |
| 某项指标一直忽高忽低？体检报告为什么看不出问题 | AI能帮你从一堆数据里看出趋势 |
| 孩子总喊不舒服？家长要注意这个信号 | 一个AI助手，全家人的记录都能分开管 |

> 示例说明：左侧为典型违规标题模式（疾病名/症状名/药物名+AI产品名），右侧为合规改写。使用时将具体场景替换为自己的内容。

## 二、脚本内容撰写规则

### 2.1 叙事结构合规对照表

| 维度 | ✕ 禁止 | ✓ 建议 |
|---|---|---|
| 内容定位 | 以"解决健康/疾病问题"为核心叙事 | 以"展示AI产品技术能力"为核心叙事 |
| 场景切入 | 用户出现症状→AI分析疾病→给出就医建议 | 生活场景→AI功能展示→技术亮点→使用体验 |
| 诊断推理 | 展示AI对具体疾病/症状的分析判断过程 | 展示AI"做了什么操作"（追问、整理、记忆） |
| 就医建议 | 建议去XX科室、拨打120、做XX检查 | 不给具体就医建议，最多说"如有需要可咨询专业人士" |
| 药物提及 | 提及具体药物商品名或品牌名 | 不提及药物名；如必须提及，使用通用名 |
| 用户案例 | 以"用户案例+疾病"为叙事（如从症状A推理出疾病B的过程展示） | 以"用户使用体验"为叙事，不涉及具体疾病 |
| 功能展示 | 长篇幅介绍体检报告/用药/医疗器械功能（超30秒） | 30秒内展示一个亮点功能 |
| 联系方式 | 视频中留电话、二维码、引导加微信 | 不留任何联系方式 |

### 2.2 ✕ 当前结构（高危）

用户故事 → 症状描述 → AI分析疾病 → AI给出就医建议 → 免责声明

问题：即使有免责声明，内容主体仍是"疾病分析+就医指导"

### 2.3 ✓ 建议结构（低风险）

生活场景 → AI功能展示 → 技术亮点 → 使用体验 → 引导体验

重点：展示AI"做了什么操作"（追问、整理、记忆），而非"得出了什么医学结论"

## 三、安全内容方向

### 方向一 · AI技术能力展示（纯产品视角）

- **追问能力**：面对模糊提问时主动追问，不涉及具体疾病
- **信息整理**：把杂乱信息整理成结构化输出（不提"体检报告"，改称"一份文件/一堆数据"）
- **长期记忆**：记住用户之前说过并在后续调用
- **家庭成员识别**：区分"我在问自己""我在问孩子""我在问父母"

### 方向二 · 技术发布会内容

- 大模型升级亮点（纯技术参数展示比"医学诊断场景"更安全）
- 发布会预告/回顾
- 与通用AI的对比（展示差异，但对比内容不涉及具体疾病诊断）

### 方向三 · 生活方式场景（弱医疗关联）

- "AI助手就像一个随身备忘录"——信息整理工具定位
- "全家人的信息管家"——家庭档案管理视角
- "比搜索引擎更懂你的AI助手"——日常问答体验视角

## 四、脚本撰写自我审查清单（脚本阶段）

1. 标题是否出现疾病名称、症状名称、药物名称？→ 改写
2. 视频中是否有AI对具体疾病/症状的分析判断？→ 删除或改为功能演示
3. 是否出现具体就医建议（科室、检查项目、是否拨打120）？→ 删除
4. 是否展示具体生命体征数据（血压值、血糖值）？→ 删除或模糊化
5. 是否出现"医生""专家""诊疗""诊断"等暗示医疗身份的词？→ 改为"AI助手""智能分析"
6. 是否有引导用户讨论病情的互动语？→ 删除
7. 是否长篇幅介绍医疗功能（超30秒）？→ 精简或拆分
8. 是否留有联系方式或引导加微信？→ 删除
